# Nafis Aslam Portfolio

A personal portfolio website built with Next.js. The repository includes a public-facing site and supporting content, components, and profile material.

## Tech
Next.js, React, Tailwind CSS, and the libraries listed in `package.json`.

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000 during development. Review the environment configuration before enabling database-backed or admin features.
